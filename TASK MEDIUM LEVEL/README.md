## Task 1 - Spam Email Classifier

### Description

Developed a machine learning based spam email classifier using Python and Scikit-learn. The system classifies email messages as either spam or non-spam based on their text content.

### Implementation

- Created a dataset containing spam and non-spam email messages.
- Split the dataset into training and testing sets.
- Applied TF-IDF vectorization to convert text messages into numerical features.
- Trained a Multinomial Naive Bayes classification model.
- Evaluated the model using accuracy and classification metrics.
- Added an interactive feature for entering new messages.
- The trained model predicts whether a new message is spam or non-spam.
- Displays the prediction confidence for the input message.

### Technologies Used

- Python
- Scikit-learn
- TF-IDF Vectorizer
- Multinomial Naive Bayes

## Task 3 - AI Tic-Tac-Toe

### Description

Developed a console-based Tic-Tac-Toe game in Python where the user plays against an AI opponent.

### Implementation

- Created a 3x3 Tic-Tac-Toe game board.
- Implemented user input and board position validation.
- Implemented win and draw detection.
- Added an AI opponent using the Minimax algorithm.
- The AI evaluates possible moves and selects the optimal move.
- Implemented game state evaluation for determining winning, losing, and draw conditions.
- Added input validation to prevent invalid or occupied positions.
- Implemented the complete game loop until a winner or draw is determined.

### Technologies Used

- Python
- Minimax Algorithm
- Game State Evaluation
- Console-Based Interface
